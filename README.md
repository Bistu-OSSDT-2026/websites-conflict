# 🛡️ 网站冲突 (Website Conflict)

> **核心创新**：基于 **Logux** 框架的实时协同与渗透演练，在同步中对抗，在对抗中构建。

---

## 📖 项目简介

「网站冲突」是一款专为网络安全与全栈开发设计的实战演练游戏。选手将在同一服务器环境下，经历从**快速构建**到**激烈攻防**的完整闭环，全方位锻炼网站搭建、漏洞修复及渗透测试能力。

---

## ⏱️ 赛程规则

### 第一阶段：⚡ 极速构建（前 1 小时）

- **环境**：所有选手在**共同服务器**上并行开发。
- **工具**：支持使用提供的**图形化组件**辅助开发，降低重复造轮子成本。
- **硬性指标**：
  1. 完成个人网站搭建。
  2. **必须**包含一条通往本机的网络通道（为后续攻防预留入口）。

### 第二阶段：⚔️ 全面渗透（后 2 小时）

- **模式**：全场同时开启，无差别对抗。
- **目标**：
  1. 渗透他人网站，寻找突破口。
  2. 打通通往**他人本地数据库**的路径。
  3. 窃取数据库内的 **"敏感信息"** 以获取积分。

---

## 🚀 技术亮点

### 💡 Logux 框架深度应用

本项目创新性地将 **Logux** 引入渗透演练场景：

- **实时状态同步**：利用 Logux 的 CRDT 与日志同步机制，实现攻防状态的毫秒级广播。
- **协同式开发**：在构建阶段，选手可基于 Logux 快速搭建具备实时交互能力的后端架构。
- **动态攻防链路**：渗透过程中的状态变更通过 Logux 协议流转，让"发现漏洞 → 利用漏洞 → 获取数据"的链路更具实时反馈感。

## 📝 参赛须知

1. **禁止破坏服务器**：所有攻击行为仅限选手个人站点及通道，严禁对公共基础设施进行 DDoS 或提权。
2. **数据合规**：仅可窃取游戏预设的"敏感信息" Flag，严禁读取其他选手的私人账号密码或系统文件。
3. **工具限制**：允许使用常规渗透工具，但禁止使用自动化一键脚本（需手动验证漏洞利用过程）。
